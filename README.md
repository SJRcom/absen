# Absensi SJR

Buatkan aplikasi absensi kehadiran menggunakan kartu etoll dan HP NFC. Juga berfungsi untuk pembayaran tiket masuk penggunaan lapangan sepak bola. Setiap lapangan memiliki harga masing-masing. Dan setiap peserta punya tarif berbeda

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://absen.sjr-komunitas.com/ (production) · https://absensjr.lovable.app/ (Lovable preview)

Panduan pindah ke hosting sendiri (VPS/Cloudflare/statis) ada di [DEPLOYMENT.md](./DEPLOYMENT.md).
